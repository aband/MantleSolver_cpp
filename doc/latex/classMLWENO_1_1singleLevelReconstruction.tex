\doxysubsection{Detailed Description}
Single level reconstruction class. 


\begin{DoxyEnumerate}
\item Create non-\/overlap stencils with given stencil size.
\item Compute stencil polynomials with created stencils.
\item Calculate smoothness indicators with stencil polynomials. 
\end{DoxyEnumerate}
