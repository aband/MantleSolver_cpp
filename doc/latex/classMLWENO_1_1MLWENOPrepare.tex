\doxysubsection{Detailed Description}
A class preparing for all possible multi-\/level weno reconstruciton using different single-\/level reconstruction. This class holding all single level reconstuctions. Let \doxylink{namespaceMLWENO}{MLWENO} \char`\"{}steal\char`\"{} single level reconstructions from it. Multi-\/level reconstruction class is declared as a friend of this class.
