\section{Parallel Implementation}
In this section, we disscuss some ideas regarding parallel implementation
of MFEM and FVM solvers, and present some preliminary timing results for each 
solver.
The parallel implementation of the MFEM and FVM need different treatments.
For MFEM solver, edge dofs are shared across different processors.
